## 一、项目简介

一个「住在包挂里的小东西」——低成本硬件（ESP32-S3 圆屏 + 六轴 IMU）上的养成型电子宠物。

核心一句话：**外壳是它的"家 / 容器"，圆屏里住着一个会成长、有性格、会说话的小生命。**

- 不是"电子宠物"，而是"被你的生活方式养成的第二人格"
- 外壳从买到手那天起就固定不变，**所有成长只发生在圆屏内部**
- 你怎么生活，它就变成什么样：走路 / 跑步 → 活力；常摸 → 黏人；猛摇 → 顽皮
- 熟悉度决定它怎么跟你说话：陌生时客气，死党时没大没小

## 四、已完成 ✅

**产品概念**
- [x] 固定外壳 = 家 / 容器，成长只发生在圆屏内部
- [x] 4 个角色：麦啰（吐司）、咕杯（咖啡）、咔米（相机）、莓噜（草莓奶）
- [x] 每角色 10 阶段成长叙事线（如麦啰：面粉 → 加蛋 → 搅拌 → 面团 → 发酵 → 入炉 → 烘烤 → 出生 → 抹黄油 → 性格进化）

**视觉 / 交互**
- [x] Labubu 式软胶盲盒玩具外观（高光软胶壳、金属挂环、锯齿牙咧嘴笑大眼珠）
- [x] 成长动画：呼吸起伏、眨眼、进化「爆闪 + 星光」
- [x] 说话文字全部在圆屏内（无屏幕外气泡）
- [x] 丰富的对话台词库：每角色 4 档熟悉度 × 6 句，且随机不重复

**养成系统**
- [x] 熟悉度系统（陌生 / 认识 / 熟人 / 好朋友 / 死党 / 老搭子），语气随之变化
- [x] 性格系统（活力 / 黏人 / 顽皮），由 energy / cling / mischief 数值驱动
- [x] 性格进化树可视化（成年体 → 三分支，含各分支专属配色与表情）

**社交 / 基因**
- [x] 宠物社交 + 情侣「贴贴」动画（见面 → 靠近 → 冒爱心，恋爱后持续贴贴）
- [x] 基因 / 宝宝：可视化孵化（蛋 → 破壳 → 宝宝），继承 Body / Feature / Color / Trait

**硬件 / 部署**
- [x] iPhone 运动传感器接入（`devicemotion`，走路 / 猛摇触发）
- [x] GitHub Pages 自动部署
