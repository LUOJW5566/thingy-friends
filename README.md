## 一、项目简介

一个「盲盒开出来的、住在包挂里的小生命」——低成本硬件（ESP32-S3 圆屏 + 六轴 IMU）上的养成型情绪陪伴宠物。

核心一句话：**先开一颗盲盒蛋，再把它养成一只独一无二、会随你生活长大的小东西。**

- 外壳是它的"家 / 容器"，从买到手就固定不变，**所有成长只发生在圆屏内部**
- 每只宠物从一颗**蛋**开始，开出同物种的**随机颜色形态 + 稀有度**（盲盒感）
- 你怎么生活，它就变成什么样：走路 → 活力·探险，跑步 → 活力，摸摸 → 黏人，猛摇 → 顽皮，冷落 → 佛系
- 熟悉度决定它怎么跟你说话；每只宠物被摸时的反应各不相同

## 四、已完成 ✅
